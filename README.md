## BeSffy는?

BeSffy는 **지금 쓰고 있는 Windows PC**에 경량화 설정을 적용하는 도구입니다.
Windows를 새로 설치하지 않아도 불필요한 기본 앱, 광고·추천, AI·원격 분석 기능, 백그라운드 실행, 시작 프로그램을 정리해서 메모리와 리소스를 아낄 수 있습니다.

- **파일 하나로 끝:** `BeSffy.cmd` 하나만 있으면 됩니다. 따로 설치할 것이 없습니다.
- **PC마다 직접 고르기:** 무엇을 적용할지, 어떤 앱을 지울지, 어떤 앱의 백그라운드 실행을 허용할지 창에서 하나씩 고릅니다.
- **먼저 보고, 나중에 적용:** 미리보기로 바뀔 내용을 먼저 확인하고, 마음에 들면 그때 적용합니다.
- **되돌리기 가능:** 적용하기 전에 복원 지점과 백업을 자동으로 만들고, 메뉴에서 바로 되돌릴 수 있습니다.

## 요구 사항

| 항목 | 내용 |
| --- | --- |
| 운영 체제 | Windows 11 64비트 (Windows 11 26H2에서 개발·테스트) |
| 권한 | 관리자 권한 (실행하면 자동으로 요청합니다) |
| PowerShell | Windows에 기본으로 들어 있는 Windows PowerShell 5.1 (PowerShell 7에서 열려도 자동으로 5.1로 다시 엽니다) |
| 실행 위치 | 바탕화면·문서처럼 **파일을 쓸 수 있는 일반 폴더** (보고서와 백업이 이 폴더에 생깁니다) |

## 사용법

### 1. 내려받기

[Releases](../../releases) 또는 이 저장소에서 `BeSffy.cmd`를 내려받아 바탕화면 같은 일반 폴더에 둡니다. (Release의 `BeSffy.cmd.sig`는 자동 업데이트가 쓰는 서명 파일이라 받지 않아도 됩니다.)

> [!WARNING]
> 압축 파일 안에서 바로 실행하거나 USB·CD 같은 읽기 전용 위치에서 실행하지 마세요. 백업과 보고서를 저장하지 못하거나, 임시 폴더에 생겨 나중에 사라질 수 있습니다.

### 2. 실행하기

`BeSffy.cmd`를 더블클릭하고, 권한을 묻는 창에서 **예**를 누르면 메뉴가 열립니다.

> [!NOTE]
> BeSffy는 코드 서명이 되어 있지 않아서, 처음 실행할 때 Windows가 막을 수 있습니다.
>
> - **"Windows의 PC 보호" 창이 뜨면:** **추가 정보** → **실행**을 누르세요.
> - **더블클릭해도 열리지 않으면:** 파일을 마우스 오른쪽 버튼으로 눌러 **속성** → 아래쪽 **차단 해제** 체크 → **확인**을 누르세요.
>
> 한 번 열리면 BeSffy가 "인터넷에서 받은 파일" 표시를 스스로 지워서, 다음부터는 바로 열립니다.
>
> **네트워크 드라이브(NAS 등)에서는 실행되지 않습니다.** 관리자 권한 창에서는 네트워크 드라이브가 보이지 않아서, 바탕 화면 같은 PC 안의 폴더로 복사한 뒤 실행하세요.

### 4. 추천 순서

1. **메뉴 1 (미리보기):** 창이 차례로 열립니다. 이 PC에 맞게 고르세요.
   1. **무엇을 적용할까요:** 적용할 항목 체크
   2. **백그라운드 예외** (설정·정책을 고른 경우): 백그라운드에서 계속 돌아야 하는 앱 체크 (추천 항목 ★은 미리 체크되어 있음)
   3. **검색 색인:** 끌지, 켜 둘지 선택
   4. **[베타기능] Defender 예약 검사** (체크한 경우): 이 PC에 맞는지 추천을 보고, 가볍게 할지 그대로 둘지 선택
   5. **지울 앱** (앱 삭제를 고른 경우): 지울 앱만 체크 (기본으로는 아무것도 체크되어 있지 않음)
   6. **시작 프로그램** (시작 프로그램 정리를 고른 경우): 로그인할 때 켜 둘 것만 체크 (지금 상태대로 체크되어 있음)
2. **메뉴 2 (적용):** 적용할 내용을 한 번 더 보여 주고, 확인하면 적용합니다.
3. **다시 시작:** 적용이 끝나면 다시 시작할지 물어봅니다. 다시 시작해야 모든 설정이 적용됩니다.
4. **메뉴 3 (점검):** 다시 시작한 뒤 제대로 적용됐는지 확인합니다.

> [!TIP]
> 어느 창에서든 **취소**를 누르면 작업 전체를 멈추고, 이번에 고른 것은 저장하지 않습니다.
> 고른 값은 저장되므로 다음에 적용할 때 다시 고르지 않아도 됩니다. 바꾸고 싶으면 메뉴 1을 다시 실행하세요.

### 5. 예전 버전으로 적용했다면 (메뉴 6)

이전에 받은 BeSffy로 적용한 PC는 새 `BeSffy.cmd`를 받아 **메뉴 6**을 한 번 실행하세요. 다시 적용(메뉴 2)하지 않아도, 예전 버전이 남긴 아래 문제만 찾아서 고칠지 하나씩 물어봅니다. 문제가 없으면 아무것도 바꾸지 않으니, 언제 받았는지 모르겠으면 그냥 실행해도 됩니다.

| 확인하는 것 | 고치면 |
| --- | --- |
| 업데이트 잠금이 예전 방식 (잠가 둔 동안 Defender 정의를 안 받음, 예전 이름 LiteTools의 예약 작업·폴더·레지스트리 키) | 잠금 도구·예약 작업·바탕화면 바로가기를 새 방식으로 바꾸고, 예전 LiteTools 것은 지움. 지금 잠금·켜기 상태는 그대로 |
| Internet Explorer 기능이 지워져 Edge의 IE 모드가 안 됨 | 다시 설치 (인터넷에서 받아서 몇 분 걸림) |
| 다른 계정에 OneDrive가 있는데 PC 전체에 동기화 막기가 걸려 있음 | 동기화 막기를 풂 (지금 계정의 OneDrive는 지운 그대로) |

되돌리기·점검 쪽 수정은 새 `BeSffy.cmd`를 쓰기만 하면 적용되므로 따로 할 일이 없습니다.

### 6. 업데이트 (v1.3부터)

실행하면 메뉴가 뜨기 전에 GitHub에서 새 버전이 있는지 먼저 확인합니다.

- 새 버전이 있으면 바뀐 내용을 보여 주고 **받아서 새 버전으로 실행할지** 물어봅니다. 예를 누르면 같은 폴더의 `BeSffy.cmd`를 새 버전으로 바꾸고, 같은 창에서 새 버전으로 다시 시작합니다. 백업·고른 값은 같은 폴더라 그대로 이어집니다.
- 받은 파일은 **만든 사람의 서명이 맞을 때만** 바꿔 넣습니다. 서명이 안 맞거나, 받은 파일이 지금보다 예전 버전이면 바꾸지 않고 지금 버전으로 계속합니다.
- 인터넷이 안 되거나 GitHub에 접속하지 못하면 몇 초 안에 건너뛰고 지금 버전으로 계속합니다.
- 확인할 때 GitHub에 보내는 것은 최신 버전 번호를 묻는 요청 하나뿐입니다. PC 정보는 보내지 않습니다.
- v1.2 이전 버전은 이 기능이 없어서, 새 버전을 한 번은 직접 받아야 합니다.

</details>

<summary><b>[베타기능] Defender 예약 검사 가볍게</b> — 기본으로는 꺼져 있습니다 (검사할 때 CPU를 덜 씀)</summary>

<br>

Microsoft Defender의 예약 검사가 CPU를 평균 20%까지만 쓰게 합니다. PC가 쉴 때도 마찬가지입니다 (Windows 기본은 50%이고, PC가 쉴 때는 제한 없음).

- 실시간 보호(파일을 열 때 하는 검사)는 그대로라 보안 수준은 같고, 예약 검사가 조금 더 오래 걸립니다.
- 다른 백신(알약·V3 등)을 쓰는 PC에서는 Defender가 쉬고 있어서, 무엇을 적용할까요 창에서 이 항목을 고를 수 없게 막고 노란 안내로 이유를 보여 줍니다.
- 효과가 PC마다 달라서 기본으로는 꺼져 있습니다.
- 체크하면 다음 창에서 이 PC의 마지막 빠른 검사·전체 검사 시각과 걸린 시간, 지금 설정을 보여 주고, 이 PC에 맞는지 추천합니다. 빠른 검사가 1분 넘게 걸리면 "가볍게 하기", 1분 안에 끝나면 체감 차이가 거의 없어서 "그대로 두기"를 권합니다. 추천을 보고 직접 고르면 됩니다.

</details>

<details>
<summary><b>검색 색인</b> — Windows 검색 색인(WSearch)을 끕니다</summary>

<br>

끄면 PC가 조금 가벼워지지만, 시작 메뉴·파일 탐색기·설정·Outlook 등의 검색이 느려지거나 결과가 덜 나올 수 있습니다.
검색을 자주 쓴다면 **켜 두기**를 고르세요. 끈 뒤에도 메뉴 5에서 다시 켤 수 있습니다.

</details>

<details>
<summary><b>업데이트 잠금</b> — 원할 때만 업데이트합니다</summary>

<br>

- 자동 업데이트를 끄고 2046년까지 일시정지합니다. 예약 작업이 부팅할 때와 매일 새벽 3시부터 4시간마다 일시정지를 다시 걸어 둡니다.
- 업데이트를 잠가도 Defender 정의(바이러스 DB)는 계속 받습니다. 잠그면 Windows 업데이트로는 정의가 하루 넘게 안 들어와서, 같은 예약 작업이 돌 때마다 정의를 따로 받습니다. 다른 백신을 쓰는 PC에서는 건너뜁니다.
- 지금 설치된 Windows 버전으로 고정해서 기능 업데이트(버전 업그레이드)를 받지 않습니다.
- 드라이버를 Windows Update로 받지 않고, 다른 PC와 업데이트 파일을 주고받지 않습니다.
- 바탕화면에 **Windows 업데이트 켜기 / 끄기** 바로가기를 만듭니다.

**업데이트하고 싶을 때:**

1. 바탕화면의 **Windows 업데이트 켜기**를 실행하면 설정의 Windows 업데이트 화면이 열립니다.
2. **업데이트 확인**을 눌러 설치합니다.
3. 다 끝나면 **Windows 업데이트 끄기**를 실행합니다. 깜빡해도 3일이 지나면 자동으로 다시 꺼집니다.

</details>

<details>
<summary><b>OneDrive 제거</b> — PC와 클라우드의 파일은 지우지 않습니다</summary>

<br>

OneDrive를 제거하고, 다시 설치되더라도 동기화되지 않도록 막습니다.

- OneDrive의 "PC 폴더 백업"으로 바탕 화면·문서 등이 OneDrive 안으로 옮겨져 있으면, 파일을 열지 못하게 되는 것을 막기 위해 **OneDrive는 건너뜁니다.** OneDrive 설정 → 동기화 및 백업 → 백업 관리에서 먼저 끄세요.
- 클라우드에만 있는 파일이 있거나, 파일이 많아 다 확인하지 못했으면 제거할지 한 번 더 물어봅니다.
- 동기화 막기는 PC의 모든 계정에 적용됩니다. 다른 계정에도 OneDrive 폴더가 있거나 실행 계정과 로그인한 계정이 다르면, 진행할지 물어봅니다 (Enter만 누르면 진행하지 않음).

</details>

<details>
<summary><b>다크 모드</b> — 기본으로는 꺼져 있습니다</summary>

<br>

체크하면 앱과 시스템을 다크 모드로 바꿉니다.

</details>

Microsoft Store는 건드리지 않습니다. Edge는 지우지 않고 백그라운드 실행만 끄며, Windows 보안(Defender)은 베타기능을 체크했을 때 예약 검사 설정만 바꿉니다.

## 백그라운드 예외

설정·정책을 적용하면 스토어 앱이 백그라운드에서 돌지 않도록 막습니다. 다만 꺼 두면 동기화·알림·파일 공유가 안 될 수 있는 앱은 예외로 둘 수 있습니다.

- **휴대폰과 연결**은 항상 예외입니다.
- 클라우드·동기화, 휴대폰 연동·공유(Quick Share 등), 메신저·메일, 오디오·그래픽·제조사 도우미 앱은 **추천(★)** 으로 미리 체크됩니다.
- 앱은 프로그램별(Apple, 삼성, NVIDIA 등)로 묶여 보여서, 묶음을 체크하면 그 아래 앱이 모두 함께 체크됩니다.

적용한 뒤 알림이 안 오거나 동기화가 멈춘 앱이 있으면 **메뉴 5 → 1. 백그라운드 앱 다시 켜기**에서 골라서 다시 허용하세요.

## 되돌리기

**메뉴 4 (되돌리기)** 를 실행하면 적용 때 바꾼 것을 원래대로 돌립니다. 여러 번 적용했다면 최근 것부터 차례로 되돌려 **맨 처음 적용하기 전 상태**로 돌아갑니다.

| 되돌려지는 것 | 직접 되돌려야 하는 것 |
| --- | --- |
| 레지스트리 설정 | 지운 앱 → Microsoft Store에서 다시 설치 |
| 서비스 시작 유형 | 시스템 구성요소 → 설정 → 시스템 → 선택적 기능에서 다시 추가 |
| 업데이트 잠금 (예약 작업, 바탕화면 바로가기 포함) | OneDrive → 다시 설치 |
| 터미널 설정, 시작 메뉴 바로가기 | |
| 시작 프로그램 켜짐/꺼짐, Defender 예약 검사 설정 | |
| 예약된 저장소 | |

전체를 한 번에 되돌리고 싶으면, 적용할 때 만든 **복원 지점**("BeSffy 적용 전")으로 시스템 복원을 하세요.

백신이 BeSffy 폴더의 `regtool\BeSffyReg.exe`를 막는 등으로 레지스트리를 되돌리지 못하면, 그 백업부터는 손대지 않고 남긴 채 멈춥니다. 원인을 해결하고 메뉴 4를 다시 실행하면 이어서 되돌립니다.

## 생기는 파일

**`BeSffy.cmd`가 있는 폴더**

| 경로 | 내용 |
| --- | --- |
| `reports\` | 실행할 때마다 남는 보고서(`.txt`)와 실행 기록(`.log`) |
| `backup\` | 되돌리기용 백업 |
| `regtool\` | 설정을 넣을 때 쓰는 `reg.exe` 복사본 (Windows가 원래 이름의 `reg.exe`로는 위젯 관련 설정을 못 바꾸게 막아서) |
| `selected_options.txt` | 적용할 항목 (미리보기에서 고른 값) |
| `selected_apps.txt` | 지울 앱 |
| `selected_bgapps.txt` | 백그라운드 예외 앱 |
| `selected_startup.txt` | 끄고 켤 시작 프로그램 |

> [!CAUTION]
> `backup\` 폴더를 지우거나 `BeSffy.cmd`만 다른 폴더로 옮기면 메뉴 4로 되돌릴 수 없습니다. 폴더째로 보관하세요.

**PC에 생기는 것 (업데이트 잠금을 적용한 경우)**

- `C:\ProgramData\BeSffy\` : 업데이트 켜기·끄기·일시정지 스크립트
- 작업 스케줄러 `\BeSffy\WU-RePause` : 업데이트 일시정지를 유지하고 Defender 정의를 받는 예약 작업
- 모든 사용자의 바탕화면 : **Windows 업데이트 켜기 / 끄기** 바로가기
- 레지스트리 `HKLM\SOFTWARE\BeSffy` : 업데이트를 켜 둔 상태인지와 켠 시각

메뉴 4로 되돌리면 모두 지워집니다. 예전 이름(LiteTools)으로 남아 있던 것도 같이 지웁니다.

## 주의 사항

- **로그인한 계정으로 실행하세요.** 다른 관리자 계정으로 권한을 올려 실행하면, 사용자 설정이 로그인한 계정이 아닌 그 관리자 계정에 적용됩니다. (다를 경우 BeSffy가 알려 줍니다.)
- **업데이트를 잠그면 보안 업데이트도 받지 않습니다.** 가끔 바탕화면의 **Windows 업데이트 켜기**로 업데이트를 설치해 주세요.
- **설치를 기다리는 업데이트가 있으면** 적용 전에 한 번 다시 시작하는 것을 권합니다.
- 중요한 파일은 적용하기 전에 따로 백업해 두세요.
