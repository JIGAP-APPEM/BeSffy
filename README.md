# BeSffy

**Best SFF Optimizer**

> Keep what you use, ditch what you don't — same Windows, just lighter.

윈도우를 다시 설치하지 않고, 지금 쓰는 PC를 가볍게 만들어 주는 도구입니다.

안 쓰는 기본 앱, 광고와 추천, AI·원격 분석 기능, 쓸데없는 백그라운드 실행을 정리해서 메모리를 아껴 줍니다.
뭘 지우고 뭘 남길지는 PC마다 직접 고를 수 있어요.

## 사용법

1. `BeSffy.cmd`를 받아서 바탕화면 같은 일반 폴더에 둡니다. (압축 파일 안에서 바로 실행하지 마세요)
2. 더블클릭하고 관리자 권한을 허용합니다.
3. **1. 미리보기**에서 적용할 항목을 고르고, **2. 적용**을 누른 뒤 재부팅하면 끝입니다.

코드 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 됩니다.

## 메뉴

| 메뉴 | 설명 |
| --- | --- |
| 1. 미리보기 | 적용할 항목, 지울 앱, 백그라운드 예외를 고르고 바뀔 내용을 확인 (PC는 안 바뀜) |
| 2. 적용 | 복원 지점과 백업을 만든 뒤 적용 |
| 3. 점검 | 적용한 설정이 그대로인지, 지운 앱이 다시 생기지 않았는지 확인 |
| 4. 되돌리기 | 적용하기 전으로 되돌림 |
| 5. 일부 옵션만 복구 | 막힌 백그라운드 앱, 검색 색인, 꺼 둔 시작 프로그램만 골라서 다시 켬 |

## 뭐가 바뀌나요

전부 미리보기에서 켜고 끌 수 있습니다.

- **앱 삭제** - 체크한 앱만 지웁니다. 기본으로는 아무것도 체크되어 있지 않아요.
- **시스템 구성요소** - IE, 옛 Media Player, PowerShell ISE, Recall 등 거의 안 쓰는 기능
- **설정·정책** - 광고·추천, Copilot, 원격 분석을 끄고 스토어 앱과 Edge의 백그라운드 실행을 막습니다. 작업 표시줄과 탐색기도 깔끔하게 정리합니다.
- **시작 프로그램 정리** - 로그인할 때 자동으로 켜지는 프로그램(자동 실행·시작 폴더·스토어 앱)을 창에서 골라 끄거나 켭니다. 작업 관리자의 "시작 앱"과 같은 방식이라 프로그램은 지우지 않습니다.
- **[베타기능] Defender 예약 검사 가볍게** - 예약 검사가 CPU를 평균 20%까지만 쓰게 합니다 (PC가 쉴 때도 포함). 실시간 보호는 그대로입니다. 효과가 PC마다 달라서 기본으로는 꺼져 있습니다.
  - 체크하면 이 PC의 검사 기록(마지막 빠른 검사·전체 검사 시각과 걸린 시간)과 지금 설정을 보여 주고, 이 PC에 맞는지 추천합니다. 추천을 보고 "가볍게 하기 / 그대로 두기" 중에서 고르면 됩니다.
- **검색 색인** - 끄면 가벼워지지만 윈도우 검색이 느려질 수 있습니다.
- **업데이트 잠금** - 자동 업데이트를 끄고 지금 버전으로 고정합니다.
- **OneDrive 제거** - PC와 클라우드의 파일은 그대로 둡니다.
- **다크 모드** - 기본은 꺼져 있습니다.

## 업데이트하고 싶을 때

업데이트 잠금을 적용하면 바탕화면에 **Windows 업데이트 켜기 / 끄기** 바로가기가 생깁니다.
켜기로 업데이트하고, 끝나면 끄기를 누르세요. 깜빡해도 3일 뒤에 알아서 다시 꺼집니다.

## 되돌리기

메뉴 4를 누르면 설정, 서비스, 업데이트 잠금이 처음 상태로 돌아갑니다.

지운 앱, 구성요소, OneDrive는 되돌려지지 않으니 Microsoft Store나 선택적 기능에서 다시 설치해야 합니다.
전부 한 번에 되돌리고 싶으면 적용할 때 만든 복원 지점을 쓰면 됩니다.

## 주의

- 백업과 보고서는 `BeSffy.cmd`와 같은 폴더에 생깁니다. `backup` 폴더를 지우면 되돌리기가 안 되니 폴더째로 보관하세요.
- 업데이트를 잠그면 보안 업데이트도 안 들어옵니다. 가끔은 켜서 업데이트해 주세요.
- 알림이나 동기화가 안 되는 앱이 생기면 메뉴 5에서 그 앱만 백그라운드를 다시 허용하면 됩니다.

## 요구 사항

- Windows 11 (26H2, 25H2, 23H2에서 테스트 완료)
- 관리자 권한
